# 离线安装与维护

此包为 **PBZMC {version} 离线便携版**，已包含全部模型、纹理、字体、UI、音效及资源清单。首次运行只校验和复制本地文件，不下载工具或资源，也不现场转换资源。需要已经安装的 PBZ Steam Windows x64 版本；支持范围见 [兼容列表](COMPATIBILITY.md)。

## 安装与启动

先在游戏内保存并正常退出。Steam 库右键 PBZ → 管理 → 浏览本地文件，将压缩包内容直接解压到该目录：

```text
PBZ/
├─ Launch-PBZMC.cmd
├─ Backup-PBZMC.cmd
├─ Uninstall-PBZMC.cmd
├─ PBZMC/
│  ├─ payload/
│  └─ cache/runtime-assets/  # 全部运行资源，须完整保留
└─ platform/steam/PBZ.exe    # 用户已安装的原游戏
```

双击 `Launch-PBZMC.cmd`。首次运行会备份存档并校验本地文件，安装完成后通过 Steam 启动。以后仍使用该脚本启动。首次校验和复制需要一些时间，不要提前关闭窗口；为资源缓存、安装副本和备份预留至少 1 GB 空间。

**每次使用模组都从 `Launch-PBZMC.cmd` 启动；直接从 Steam 点“开始游戏”为原版模式。** 切换前退出游戏。脚本只对本次进程开启模组，不改 Steam 的持久启动选项，正常退出或崩溃后无需卸载。旧版升级后运行一次新版 CMD 才会换上默认关闭的加载器。

若曾手动把 `--pbzmc` 加到 Steam“启动选项”，请移除，否则正常 Steam 启动也会启用模组；`--disable-ue4ss` 则优先禁用，使用模组时应移除它。安装器不会改动玩家的启动选项。

## 备份与恢复

原生存档 `ProjectPBZ/Saved/SaveGames/`、`ProjectPBZ/Saved/*.sav` 与模组数据 `platform/steam/ue4ss/Mods/PBZMCProbe/Scripts/pbzmc-data/` 应一起备份。

双击 `Backup-PBZMC.cmd`，备份位于 `PBZMC/backups/日期-编号/`。建议升级前保留一份配对备份，并在游戏目录以外留一份重要进度；不必每次启动或每章重复备份整个目录。恢复时关闭游戏和自动同步，先保留当前文件，再将同一次备份的原生存档和模组数据按原路径一起恢复。不要混合不同时间点的数据。

建筑和物品变化仅在原生存档点实际保存时写入，文件备份不能代替游戏内保存。Steam 云存档通常不会替你备份模组数据。

## MC 旧档恢复与大小限制

原生存档的模组标识正常、但对应 MC 检查点缺失或损坏时，模组会自动创建独立的 MC 数据，显示恢复提示。PBZ 剧情进度和原存档不重置，失败的 MC 文件保留在原位置。恢复后的背包、建筑和冷却重新开始，正常玩到原版存档点后保存；恢复动作本身不会调用 PBZ 保存。

恢复记录按原生检查点复用。反复读取同一失败档不会重复复制目录或生成恢复分支，仅增加一份很小的关联记录；读回旧检查点时也不会串入后来才保存的 MC 数据。若需要原背包和建筑，请使用同次配对备份恢复。

原生 JSON 桥当前支持最多 8 MiB UTF-8、400000 个 JSON 值，写入另留 4 KiB 安全余量。磁盘上的 `.sav` 大小与解码后的 JSON 不等价。原生 JSON 超限／损坏、桥版本不匹配或磁盘读写错误会明确报错并停止重试，不通过重建 MC 数据掩盖这些错误。正常游玩不反复解析整份原生 JSON，也不逐帧写入存档。

## 更新、卸载与故障

- 旧版若首次进档只有史蒂夫、没有背包，或备份时报“未能找到路径的一部分”，可能是检查点／备份文件超过 Windows 传统路径长度限制。修复版支持扩展路径，保留旧数据格式，无需修改注册表。先退出游戏，完整解压修复版到原目录，运行新版 `Backup-PBZMC.cmd` 后再启动；不要先卸载或删除 `pbzmc-data`。
- 存档文件读写失败时会显示 MC 读档错误，`UE4SS.log` 中 `PBZMC-IO` 记录操作、路径长度和错误码。失败的初始化停止重复创建数据；检查目录权限／磁盘空间，解决后重载或重启。
- 更新前保存、退出并备份，然后完整解压对应的新包。不要混用不同版本的安装器与资源清单。
- `Uninstall-PBZMC.cmd` 会再次备份，只删除归属记录和哈希匹配的模组文件，保留存档、缓存和修改过的文件。
- 资源缺失或损坏时会报错并停止，不尝试联网。重新完整解压同版离线包后启动即可。
- 较新的官方 UE 5.7 构建可在本机自动定位。若提示 `PBZMC-HOST`，请把游戏版本和失败入口发到 GitHub Issues。
- 已安装其他 UE4SS 加载器或模组时，同名文件可能冲突；脚本不会强行覆盖不同文件。
- 检查安装：`powershell -NoProfile -ExecutionPolicy Bypass -File .\PBZMC\Manage-PBZMC.ps1 -Action Verify`。

模组资源本身不需要联网；Steam 和游戏是否可以离线启动，仍由原游戏决定。
