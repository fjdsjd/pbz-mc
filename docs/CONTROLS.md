# 按键

| 按键 | 功能 |
| --- | --- |
| B | 打开／关闭背包；容器内鼠标操作物品 |
| F5 | MC 第一人称／PBZ 原版视角 |
| F6 | 开启／关闭 PBZ 武器自动防御，启动游戏时默认关闭 |
| H | 关闭／再次查看操作提示 |
| 1–9、滚轮 | 选择统一快捷栏，PBZ 原生槽位与 MC 物品共用 |
| 容器内 1–9 | 交换鼠标悬停格与对应快捷栏格 |
| Ctrl + 左键 | 背包内快速移入垃圾槽 |
| 左键 | 当前 MC 武器攻击／持续挖掘／攻击船；PBZ 武器按原生规则 |
| 右键 | 放置、使用、食用、上船；手持护甲可交换对应部位 |
| 右键 + 副手盾 | 格挡立即生效；攻击优先，结束后恢复持续举盾 |
| 弓 + 副手盾 | 未举盾时右键拉弓、松开发射；保持已有举盾时左键拉弓、松开发射并回盾 |
| 矛 | 左键点刺。按住右键架矛，瞄准敌人并疾跑，迎面接近越快，冲锋伤害越高 |
| 重锤 | 左键挥击。下落超过 1.5 格时瞄准敌人挥锤，可以发动下砸 |
| 风弹 | 主手右键投掷。主手为空、持剑、镐或重锤时，也可右键投出副手风弹。朝脚边投掷可风跳 |
| Space | MC 跳跃，持续按住连续跳；PBZ 攀爬仍沿用原生动作 |
| Shift | MC 潜行防止滑出边缘；从船上下来 |
| Ctrl | MC 疾跑，保持到停止移动；创造飞行时加速 |
| ` | 连锁采集相邻同类模组方块 |
| / | 打开命令行；Enter 提交，Esc 关闭 |
| Tab / Shift+Tab | 命令补全／反向补全 |
| 命令行 ↑ / ↓ | 上一条／下一条历史命令 |
| 对命令方块按右键 | 编辑命令、种类、条件、红石模式与输出记录；点击完成保存设置 |

按 B，在「工具与武器」中可取得木、石、铜、铁、金、钻石或下界合金矛。点刺和冲锋都能刺中同一直线上的多个敌人。生存模式的有效距离为 2 至 4.5 格，贴得太近时先拉开距离。各材质的起手时间不同。架矛后，只要敌人仍在射程内、沿矛尖方向的相对速度达标，就会持续造成伤害。减速后再次加速也能继续命中，全程可以按住右键。

两种视角都能看出举矛的阶段：先端平矛尖，疲劳后矛尖逐渐抬高并轻颤，最后压低。后段仍可凭速度造成伤害；松开右键立即结束冲锋，手上的矛再收回。动作阶段参考[基岩版官方说明](https://www.minecraft.net/en-us/article/minecraft-1-21-130-bedrock-changelog)，命中回弹参考[原版矛动画](https://github.com/Mojang/bedrock-samples/blob/15701fa9c13923f12662984c32c124327e40e3d3/resource_pack/animations/spear.animation.json)。

重锤在「工具与武器」分类中领取。普通挥击完全恢复约需 1.67 秒。下砸按实际下降距离增伤，砸中会击退附近的敌人，并从命中高度重新计算坠落。砸空仍承受原版落地伤害。致密 V 增加下砸伤害，破甲 IV 削弱目标物理抗性的效果，风爆 I–III 会把自己向上弹起，可以接下一锤。目录也有致密或破甲搭配风爆 III 的组合款。

风弹也在「工具与武器」分类中。主副手共享 0.5 秒冷却，默认自由玩法可重复投掷。飞行时弹芯和外壳反向旋转，击中表面或敌人时会冒出两波白色阵风。带风爆附魔的重锤下砸命中时，脚边会连续八个游戏刻卷起范围更大的阵风。

风弹直击敌人会造成少量伤害，风爆会推动附近的人物、船和已点燃的 TNT。风跳按受到风压时的高度计算后续摔伤。可以隔空拨动拉杆、开关木门、吹灭地火。墙体会挡住风压。风弹飞出 5 个游戏刻后，可以用左键挥击或箭矢将它打向新的方向。

选中 PBZ 武器后，按 F6 开关自动防御。普通攻击和蓝光尝试完美格挡，原生标记为需要闪避的红光尝试完美闪避。遇到围攻时按命中时间处理，同一帧内优先闪避不可格挡的攻击。近身敌人的攻击预报和飞向玩家的投射物可以提前触发防御准备，最终结果由 PBZ 判定。切到 MC 物品、打开背包或进入过场时暂停。按 H 可以重看或关闭快捷键提示。

创造模式下，双击空格切换悬停飞行，按住空格上升、Shift 下降、Ctrl 加速。穿上鞘翅后，走下高处再单按空格即可滑翔。从地面起跳时，两次按空格之间留出至少 0.35 秒即可展翼。滑翔时右键使用烟花助推，双击空格可切回悬停。已在悬停时，先双击退出，再松开并单按空格即可展翼。两种视角都支持这些操作。

在「护甲」分类领取海龟壳并戴在头部。眼睛露出 MC 水面时，水下呼吸会补满到 10 秒。潜入水中后先用这 10 秒，再消耗平时的 15 秒氧气。气泡显示剩余氧气，背包显示效果倒计时。摘下海龟壳后，已经获得的时间仍然有效，在水下重新戴上要等到露出水面才会补满。

在 **B → 药水** 领取药水和牛奶桶。持续按右键 1.6 秒饮用，喷溅／滞留药水按右键投掷；副手按既有主手优先规则使用。喷溅和滞留可作用于玩家、MC 生物及 PBZ 生物，牛奶清除自身效果。冒险模式消耗饮用品并返回空瓶／空桶，自由和创造模式不消耗。详见[药水说明](POTIONS.md)。

在 **B → 自然** 翻页领取刷怪蛋。目录包含 MC 26.3 的 88 种原版刷怪蛋，以及巨人、幻术师、杀手兔三个指令生物的召唤蛋。主手或副手持蛋，瞄准附近有足够空间的地面按右键。水生生物也能直接放进 MC 的水中。

召唤物会跟随玩家。牛、羊、村民等和平生物只跟随，具有攻击能力的生物会主动寻找约 16 格内可见的 PBZ 敌人。苦力怕在敌人进入 2.5 格时开始闪烁，1.5 秒后自爆。敌人脱离 6 格或躲到墙后，引信会回退。也可以用打火石直接点燃它。爆炸能伤敌、破坏附近的 MC 建筑和引爆 TNT，友方爆炸保护玩家。

硫方怪以体内含岩浆块的灼热形态出现，会靠近敌人造成接触伤害。场上最多同时存在 12 只召唤物。手持任一刷怪蛋，按住 Shift 并右键点中一只即可解散。亡灵可以在日光下活动。切换地图或重新读档会清理召唤物。

**刷怪笼**也在背包的「自然」分类。将它放到地上，手持刷怪蛋对准笼子按右键，笼内就会显示对应的生物。换一枚蛋再按右键即可更换种类。附近要给生物留出足够空间。玩家在 16 格内时笼子才计时，通常每隔 10～40 秒尝试刷出一批，附近已有 6 只同类时会等待。手动召唤和所有笼子共用 12 只的总上限。拆除笼子会停止刷新，已生成的生物可以用 Shift＋右键解散。笼子的位置和所选种类随原版存档点保存。

游戏内操作提示包含 B／F5 按键、攀岩和马车战建议。每次启动进入玩法后显示 12 秒，之后自动隐藏；H 可提前关闭或再次查看。背包、过场和原生界面接管时隐藏并暂停计时，不会因切换物品或读档反复弹出。

**遇到影之刃攀岩，请切换到影之刃主武器进行攀岩；马车战建议使用影之刃原版武器。**
