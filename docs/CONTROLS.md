# 按键

| 按键 | 功能 |
| --- | --- |
| B | 打开／关闭背包；容器内鼠标操作物品 |
| F5 | MC 第一人称／PBZ 原版视角 |
| F6 | 开启／关闭 PBZ 武器自动防御，启动游戏时默认关闭 |
| H | 关闭／再次查看操作提示 |
| 1–9、滚轮 | 选择统一快捷栏，PBZ 原生槽位与 MC 物品共用 |
| 容器内 1–9 | 交换鼠标悬停格与对应快捷栏格 |
| Ctrl + 左键 | 背包内快速移入垃圾槽 |
| 左键 | 当前 MC 武器攻击／持续挖掘／攻击船；PBZ 武器按原生规则 |
| 右键 | 放置、使用、食用、上船；手持护甲可交换对应部位 |
| 右键 + 副手盾 | 格挡立即生效；攻击优先，结束后恢复持续举盾 |
| 弓 + 副手盾 | 未举盾时右键拉弓、松开发射；保持已有举盾时左键拉弓、松开发射并回盾 |
| Space | MC 跳跃，持续按住连续跳；PBZ 攀爬仍沿用原生动作 |
| Shift | MC 潜行防止滑出边缘；从船上下来 |
| Ctrl | MC 疾跑，保持到停止移动；创造飞行时加速 |
| ` | 连锁采集相邻同类模组方块 |
| / | 打开模式命令行，仅接受 `gamemode creative`、`gamemode survival` |
| Tab / Shift+Tab | 命令补全／反向补全 |

选中 PBZ 武器后，按 F6 开关自动防御。普通攻击和蓝光尝试完美格挡，原生标记为需要闪避的红光尝试完美闪避。遇到围攻时按命中时间处理，同一帧内优先闪避不可格挡的攻击。近身敌人的攻击预报和飞向玩家的投射物可以提前触发防御准备，最终结果由 PBZ 判定。切到 MC 物品、打开背包或进入过场时暂停。按 H 可以重看或关闭快捷键提示。

创造模式：双击 Space 进入／退出飞行，Space 上升，Shift 下降，Ctrl 加速。鞘翅占胸甲位，空中重新按 Space 展开，烟花可助推。视角、玩法模式和武器选择相互独立。

游戏内操作提示包含 B／F5 按键、攀岩和马车战建议。每次启动进入玩法后显示 12 秒，之后自动隐藏；H 可提前关闭或再次查看。背包、过场和原生界面接管时隐藏并暂停计时，不会因切换物品或读档反复弹出。

**遇到影之刃攀岩，请切换到影之刃主武器进行攀岩；马车战建议使用影之刃原版武器。**
