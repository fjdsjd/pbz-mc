# 生物模型与动画

模型、贴图、动画和控制器以 Mojang/bedrock-samples 提交 `15701fa9c13923f12662984c32c124327e40e3d3` 为基准；索引和哈希见 `src/content/mob_visual_reference.json`。实体提供的动画状态、鸡扑翼、鱿鱼触手、史莱姆压缩、龙飞行历史及坚守者攻击时序另核对本地 Minecraft Java 26.3 源码。原始资源与反编译文件不随公开源码提交。

转换保留骨骼父子关系、原始 UV、镜像、每个方块的旋转支点和旧几何的绑定姿态。省略方块支点时使用方块中心；模型与贴图须来自匹配的客户端定义。羊的原版材质将 Alpha 用于染色，所以脸部和蹄子不能按透明裁剪处理。参见 [Mojang 模型来源](https://github.com/Mojang/bedrock-samples/tree/15701fa9c13923f12662984c32c124327e40e3d3/resource_pack/models/entity) 和 [原版材质规则](https://learn.microsoft.com/en-us/minecraft/creator/documents/material-files?view=minecraft-bedrock-stable)。

运行时编译并缓存 Molang 表达式，只输入宿主实际位置、目标、地面、水中、受击和攻击状态。原版控制器决定姿态，不用同一个正弦动作替代全部生物。保留旧狼动画以 24 为 Y 原点的绝对位置约定，现代偏移动画仍相对于绑定姿态。几何、纹理、表达式及关键帧共享；只更新变化的部位，远处降低视觉采样频率。

潜影贝的开壳程度由原版实体状态提供：攻击时完全开启、失去目标后闭合，空闲时短暂探头；以每游戏刻 0.05 平滑变化，再交原版开壳位移和旋转曲线。头部独立朝向目标，底壳不跟随瞄准旋转或追逐滑动。保留既有跟随距离过远时安全传送的适配。开合音效只在状态切换时触发，多个潜影贝共用声音和姿态更新预算。

验证分为资源校验、规则检查与游戏实测：`python tools/check_mob_visuals.py --assets <undead资源目录>` 检查资源哈希、四腿相位、狼肩部和腿部坐标、羊面部不透明、鸡扑翼及 91 种生物的控制器执行。生物能够生成或控制器能够执行不等于所有外观和状态均已逐个实机验收。尚未进入的原版繁殖、骑乘等状态不能由此认定可用。

本开发版已对坚守者近战和隔墙音波进行了真实 PBZ 伤害测试。狼、羊、鸡另用临时场地检查正侧面、行走和扑翼。测试不写入原生存档；这不代表任意数量的生物都能保持同样帧率。
